# Theater Utils

A tool that hooks into Halo MCC's theater mode and gives you hotkeys for clipping films: record, stop, pause, skip around, and (on Reach) save the clip out as a `.film`.

## Support?

- **Halo: Reach** - yep, works fine. Record, stop, save, all good.
- **Halo 3 / Halo 3: ODST** - kinda. It attaches and some of it works (pause, skip-forward, partial film-error blocking), consider it experimental.

## How to use it
| Key |  |
|-----|--------------|
| F1  | Keep the film open (stops it auto-exiting at the end) |
| F3  | Toggle keyframe capture |
| F4  | Abort / unstick if recording gets stuck |
| F5  | Start recording (do this while the film is playing) |
| F6  | Stop recording |
| F7  | Show the keyframe list (what skip can jump to) |
| F8  | Pause / play |
| F9  | Skip back ~10s |
| F10 | Skip forward ~10s |
| F12 | Save the clip (Reach only) |
| ESC | Undo everything and quit |
